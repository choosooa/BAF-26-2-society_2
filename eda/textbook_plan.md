### 0.2 서술 원칙

- 데이터만 다룬다. 관측한 사실과 해석을 구분하고, 해석이 불확실하면 사실만 적는다.

- 모든 그림·표 아래에 **관찰**(무엇이 보이나) 1~2줄과 **→ 시사점**(모델링에서 무엇을 할지) 1줄을 붙인다.
- 본문 수치는 결과 파일(JSON)에서 읽어 채운다. 손으로 옮기지 않는다.

## 1장 데이터 개요 — 무엇을, 어떤 단위로 예측하나

| 절 | 내용 | 출처 | 우선 |
|---|---|---|---|
| 1.1 문제 정의 | 타깃 = max(WL(t+1h … t+6h)) − WL(t), 단위 m, 음수 허용. 평가 = test 전체 행의 단일 RMSE | README | **필수** |
| 1.2 출처와 병합 구조 | 원천 5종(WAMIS 수위, IMERG, 지상강수, 레이더, DataON 유역)의 공간 단위가 서로 다르다. 여러 관측소가 같은 강우·유역 값을 공유한다(IMERG 시계열 300종/463곳, 유역 조합 329종/465곳) | ♻️ 02b | **필수** |
| 1.3 관측 단위 | 한 행 = (관측소, 시각). 입력은 과거 24h 요약, 타깃은 미래 6h. 이웃 행끼리 타깃 구간이 최대 5h 겹친다 | ♻️ 02a | **필수** |
| 1.4 변수 분류표 | 26개 변수의 역할(식별·동적·정적·타깃), 측정 척도(명목·순서·구간·비율), 단위, 시간 변화 여부 | 🆕 표 1-1 | **필수** |
| 1.5 패널 구조 | 관측소 465 × 호우사상 152(train 122 / test 30) × 시간. 사상은 1시간 넘는 공백으로 나뉜 합성 시간 구간이다(길이 중앙값 9~10h, 최대 155h). 사상마다 관측소의 98%가 등장한다 | ♻️ 02c, 02d | **필수** |

**1.4가 뒤 분석의 근거가 되는 방식**
- 수위는 관측소마다 기준면이 다른 **구간 척도**다. 관측소 간 절대값 비교는 무의미하고 변화량만 의미가 있다(→ 3.3에서 차분 사용).
- 하천차수는 순서 척도를 소권역에서 평균한 값이라 정수가 아니다.

## 12. 그림·표 규칙

- 번호는 그림·표 모두 '장-순번'이다(예: 그림 3-2, 표 2-1).
- 축에 단위와 표본 수(n)를 적는다. 치우친 변수는 log·symlog 축을 쓰고 축 제목에 밝힌다.
- 층화 그림은 전체(회색)와 비조석(색)을 같은 축에 둔다.
- 색각 이상이 있어도 구분되는 팔레트를 쓰고, 발표용은 글자를 키운 판을 따로 만든다.
