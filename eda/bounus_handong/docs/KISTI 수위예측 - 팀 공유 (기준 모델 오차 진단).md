# KISTI 수위예측 — 팀 공유 (기준 모델 오차 진단)

> 2026-10-31 · 한동 · 상세: [[KISTI 수위예측 - 모델링 전략용 EDA (기준 모델 잔차)]]
> 아래 블록을 팀 채팅에 그대로 붙인다.

```
[한동] 기준 모델 오차 진단 (dev OOF 0.2178, LightGBM 기준)

1. 예측은 이미 보정돼 있음
   - 예측 구간별 실제 평균 ≈ 예측 (예측 0.5 넘는 구간 기울기 1.02)
   - "큰 상승 과소예측(-0.44)"은 정답으로 묶어서 보이는 평균으로의 회귀
   → 튜닝·손실·후처리로는 잘 안 줄고, 기존 피처에 없는 정보가 필요

2. 오차 위치
   - 비 오는데 아직 정체 중인 행: 행 61% / 오차 47%
   - 상승 중인 행: 행 8% / 오차 37%
   - 상승 시작 행(정체인데 6h 안에 0.5m+ 상승): 행 3.3% / 오차 44%
   - 조석 15곳: 행 3.2% / 오차 9.8% (RMSE 0.38)

3. 사상 전체가 같이 틀리는 몫은 5.6%뿐 (무작위 대조 1.6%)
   - 같은 강우 격자(약 10km) 이웃끼리는 크게 같이 틀림 (0.75 vs 대조 0.44)
   - 그런데 이웃의 "현재" dwl_1h는 잔차 상관 0.07로 약함
   → 전역 동시각 피처(xs_*)를 더 늘리기보다 "시간상 앞서는" 신호가 유망

4. 잔차는 앞으로 6h 지상강수와 상관 0.18 (진단용, 피처로는 금지)
   - 미래 강우 상위 10% 행에서 평균 +0.16m 과소예측
   - 상승 시작 행의 미래 6h 강우 평균 28mm (전체 6.5mm)
   → 단기 강우 보조모델 / 선행(상류) 관측소 신호가 가장 큰 여지

제안 우선순위 (공지 후 나눠서)
 a. 선행 관측소 dwl_1h (EDA 6.6절, HGB 기준 -2.4%, Q&A 10/6 허용)
 b. q × log1p(sfc_rain_6h) (EDA 1순위, 일관성 91%)
 c. 조석 전용 모델로 구간 교체
 d. 단기 강우 보조모델 (fold 안 내부 OOF 필요, 시간 되면)
 참고: 유역×강우 단순 곱은 잔차 상관 0.01~0.02로 약함

실험 기록할 때 전체 RMSE와 함께 "상승 시작 행 SSE"도 같이 보면 좋겠음
```
