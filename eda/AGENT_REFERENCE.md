## 1. 과제 요약

- 예측 대상: `target_maxrise_6h = max(WL(t+1h)…WL(t+6h)) − WL(t)`. 단위 m, **음수 가능**
- 평가: test 전체 186,263행의 **단일 Global RMSE** (가중치·clipping 없음)
- 한 행 = (관측소, 시각). 입력은 시각 t까지의 정보만
- 데이터: `data/train.csv`(749,657행, 26열), `data/test.csv`(186,263행, 25열), `data/data_dictionary.csv`

## 3. 데이터 구조 (확인됨)

- 관측소 465곳(train/test 동일 ID), 호우사상 152개(train 122 / test 30). **train/test는 사상 단위로 분리**
- 사상 = 합성 시각에서 1시간 넘는 공백으로 끊긴 구간. 길이 중앙값 9~10h, 최대 155h
- NaN 0, 중복 0. 사상 내 빠진 시각 2.5%(강우와 무관)
- 정합성 100%: lag 컬럼 = k시간 전 행의 `wl_t`, 누적강우 = 1h 합, 타깃 = 다음 6행 최대 − wl_t
- 이웃 행끼리 타깃 구간이 최대 5시간 겹침 → 행 단위 랜덤 분할 금지
- 강우·유역 값은 여러 관측소가 공유(IMERG 시계열 300종, 유역 조합 329종) → 관측소 구별 정보는 주로 수위 이력

- 하강 중이면 대체로 계속 하강(중앙값 −0.01, 큰 하강 68% 음수). 평균 +0.016은 착시

- 가장 나은 새 변수 후보: **관측소 내 수위 분위 q × log1p(sfc_rain_6h)** (상위 5사상 제외 +2.9%, 일관성 91%)
- 기준 모델: HGB, 사상 단위 5-fold, OOF RMSE **0.2264**

**선행연구와 반대/기각된 것** (다시 파지 말 것)
- 가속도가 크면 더 오름 ❌, 감수곡선 ❌, 경사↑ 빠른 반응 ❌, 선행 습윤↑ 반응↑ ❌, 면적↑ 비유량↓ ❌

- "강한 비에서 큰 유역이 더 오름" ❌ (19사상 중 8개만 성립)
- 고정된 '선행 관측소' ❌ (반분 재현율 34%)

## 5. 분석 원칙 (반드시 지킬 것)

1. **층화**: 타깃이 들어가는 그림·통계는 **전체 vs 비조석**(조석 15곳 + ST0027 제외)을 나란히
2. **전체 확인**: 몇 개 예시로 결론 내지 말고, 관측소·사상 중 몇 %가 같은 방향인지 센다. 사상을 짝/홀로 반분해 재현되는지 본다
3. **판정 기준**(사전 고정): 70% 이상 같은 방향 = 채택, 50~70% = 부분 채택, 50% 미만 = 기각
4. **누수 방지**
   - t 이후 정보 금지: 사상 길이·끝, 사상 전체에서의 순위/최소/최대, test 안의 뒤 시각 행
   - 타깃 기반 관측소 통계(평균 인코딩 등)는 학습 fold 안에서만
   - 검증은 **사상(event) 단위 GroupKFold**
5. **이상값 제거 금지**: Tukey/MAD는 0 몰림 때문에 12~25%를 오판. 큰 비·큰 상승은 핵심 신호
6. 변환: 강우 log1p, 면적 log, 수위는 차분. 트리 모델엔 레이더 변환 불필요

## 6. 파생변수 (누수 등급: A = 행 자체로 계산, B = train 분포 필요)

| 이름 | 정의 | 등급 |
|---|---|---|
| dwl_k | `wl_t − wl_t_minus_kh` (k=1,3,6,12,24) | A |
| r1_6, r6_24 | `rain_6h − rain_1h`, `rain_24h − rain_6h` (겹치지 않는 창) | A |
| 가속도 | `1.5·dwl_1h − 0.5·dwl_3h` | A |
| q | 관측소 train 수위 분포에서 `wl_t`의 분위 | B |
| q × 강우 | `q * log1p(sfc_rain_6h)` | B |
| 댐 의심 플래그 | 마른 상승 비율 ≥ 6.15% | B |

## 9. EDA 코드 작성 규칙

사용자가 노트북(.ipynb)에서 "EDA 해줘", "분포/결측/상관 보여줘", "A랑 B 관계 봐줘"라고 하면 이 규칙대로 **코드 셀 하나**를 쓴다. 이미 로딩된 `df`를 분석하는 코드이며, 모델링·전처리 파이프라인용이 아니다.
우선순위: **1) 시각화 품질** 2) 전 컬럼 처리 3) 누수 주의 4) 짧은 구어체 해석

### 9.1 절대 규칙

1. **코드 블럭은 정확히 한 개**. 설명은 블럭 밖에 한두 줄만
2. **원본 `df` 수정 금지**. 함수 첫 줄 `data = df.copy()`. `inplace=True`, 원본 컬럼 덮어쓰기, `df = df.drop(...)` 금지
3. **모든 컬럼 포함**. 많으면 그리드 서브플롯으로 묶는다 (그림 수 관리 ≠ 컬럼 생략)
4. **표 최소화, 그림 우선**. 표는 `describe` 정도만
5. **결과물 전달은 md 파일**. 아티팩트 페이지로 발행하지 않는다
6. 데이터 로딩 코드는 쓰지 않는다

### 9.4 변수 타입 판별 (dtype만 믿지 말 것)

1. datetime이거나 안전하게 파싱되면 → 시간형
2. object/category/bool → 범주형
3. 수치지만 고유값 적음(≤10 등) → 범주형 취급 (0/1 플래그, 코드형 정수)
4. 그 외 수치 → 수치형
5. 고유값 ≈ 행 수인 object → ID형. 분포 그림에서 빼되 개요에 존재와 제외 이유를 출력

이 데이터에서는 `row_id`=ID형, `station_id`=범주형(465개, 상위 N+기타), `timestamp`=시간형(합성 시각), `stream_order`=비정수라 수치형으로 나올 수 있음. 분류 결과는 개요에서 한 줄로 출력.

### 9.5 시각화 규칙

- 모든 그림에 **제목·축 라벨(한글)**
- 수치형: 히스토그램 + KDE + 박스플롯. 행당 3~4개 그리드, 한 장 12~16개 넘으면 다음 장
- 범주형: 막대. 많으면 상위 N + "기타"
- 시간형: 라인 (조밀하면 이동평균 병기)
- 결측: 컬럼별 결측 비율 막대 + 패턴 히트맵. 결측 0이면 "결측 없음" 한 줄로 끝 (이 데이터는 NaN 0)
- 상관 히트맵: 상삼각 마스킹, 값 표시, `coolwarm`, 중심 0. 너무 많으면 |상관| 상위 쌍 막대로 보완
- **대용량**(10만 행 초과, 이 데이터 해당): 그림용만 샘플링(`random_state` 고정)하고 샘플링 사실을 출력. 통계량은 전체 기준
- 팔레트 하나로 일관. 의미 없는 무지개색 금지
- 치우친 변수(강우·면적·타깃)는 로그 축/`log1p` 시각화 병기 (복사본에서만)

### 9.7 변수 간 관계 (focus 지정 시에만)

기본 EDA는 전체 상관 히트맵까지만.

| 조합 | 시각화 | 통계량 |
|---|---|---|
| 수치 × 수치 | 산점도 + 회귀선 (이상치 있으면 로버스트) | 피어슨 + 스피어만 **둘 다** (크게 다르면 비선형/이상치 언급) |
| 범주 × 수치 | 박스/바이올린 + 그룹 평균 | 2그룹 t/맨휘트니, 3+ ANOVA/크루스칼 — 한 줄 |
| 범주 × 범주 | 비율 교차표 히트맵 | 크래머 V |
| 시간 × 수치 | 라인 + 이동평균 | 추세 방향 한 줄 |

- p-값만 던지지 말고 효과 크기와 함께 ("유의하지만 약한 관계"). 행이 75만이라 거의 모든 검정이 유의하므로 특히 중요
- "상관≠인과"는 필요할 때만 한 줄

- 포함: 결측 많은 컬럼, 두드러진 이상치, 강한 상관쌍, 치우친 분포(로그 고려), 범주 불균형, 누수 의심, 고정 문구
- 예: `"결측은 없어. 타깃은 0 근처에 몰리고 오른쪽 꼬리가 길어서 큰 상승 몇 개가 RMSE를 다 먹을 거야. 강우 6h랑 레이더는 타깃이랑 같이 움직여."`
- 그림에서 확인된 것만 말한다. 4장의 기존 사실과 다르게 나오면 그 차이를 짚는다

### 9.9 작성 전 체크리스트

- [ ] 코드 블럭 하나뿐인가
- [ ] 첫 줄이 `data = df.copy()`이고 원본을 건드리지 않는가
- [ ] 한글 폰트 설정이 있는가
- [ ] 그림마다 `plt.show()`가 있는가
- [ ] 모든 컬럼이 포함되는가 (제외한 컬럼은 이유를 출력하는가)
- [ ] 대용량 샘플링 사실을 출력하는가
- [ ] target이 있으면 누수 경고 + 고정 문구가 있는가
- [ ] 섹션 구분 주석이 있는가
- [ ] 해석이 구어체 5~8줄인가
- [ ] 돌려보지 않은 코드를 "동작 확인됨"이라 하지 않았는가
