# 01. 대회 규정 · 데이터 · 제출

출처: 대회 홈페이지 문제 설명·데이터 설명(9/23 수정본), Q&A 3건, 배포 파일(`README_PARTICIPANT.md`, `data_dictionary.csv`, `sample_submission.csv`).

## 1. 대회 기본
- 대회: 2026 DATA·AI 분석 경진대회 (KISTI). 문제: "호우 시 유역환경을 반영한 6시간 최대 하천수위 상승량 예측" (출제: 충남대 김현주)
- 홈페이지 일정 표기: **참가신청 2026-09-15 ~ 2026-11-06**
- 팀 내 목표: 11/5 제출 완료, 11/6 여유일
- 확인 필요: 11/6은 홈페이지상 "참가신청 마감"이다. 결과물 제출 마감이 같은 날인지, 참가신청서(`2026_참가신청서.hwp`) 제출을 마쳤는지 공지사항에서 확인할 것.

## 2. 문제 정의
- 한 행 = 수위관측소 1개 × 예측 기준시점 t
- `target_maxrise_6h = max(WL(t+1), …, WL(t+6)) − WL(t)`, 단위 m, 음수 가능
- 예: 현재 2.0 m, 향후 6시간 최고 2.7 m → 정답 0.7 m
- 절대 수위가 아닌 상승량을 타깃으로 한 이유: 관측소마다 하도 고도·기준면이 달라 절대 수위를 관측소 간 비교할 수 없음

## 3. 평가
- 주 지표: Hidden Test **전체 행 Global RMSE** (낮을수록 우수). clipping 없음, 관측소·사상별 가중치 없음
- 평가 구간: 강우 기준으로 정의한 호우사상만. IMERG 도메인 평균 시간강우 > 0.5 mm/h 구간을 후보로 잡고, 12시간 이하 간격은 하나의 사상으로 연결. 2017~2019년 총 152개(2017: 47, 2018: 53, 2019: 52)
- 분할: 호우사상 단위 group split. Train 122개 / Test 30개 사상
- 보조지표(관측소별 RMSE, 관측소 정규화 RMSE, 사상별 평균 RMSE)는 **순위에 반영하지 않음** (Q&A 9/23)

### 주최측 예비 기준선 (Train 749,657행, 사상 단위 4-fold OOF, 튜닝 없음)
| 모델 | RMSE (m) |
|---|---|
| 변화 없음 (전량 0) | 0.410 |
| 과거 수위만 | 0.275 |
| 강우·기상 + 유역환경 | 0.244 |

공식 Test 성능이나 통과 기준이 아닌 참고값이다.

### 비식별화
- `timestamp`: 합성 시각(2100년대). 사상 **내부**의 시간 순서와 1시간 간격만 유지. 실제 날짜·계절·시(hour) 정보 없음, **사상 간 시간 관계도 유지되지 않음**
- 사상 번호 컬럼 없음 → timestamp 끊김으로 복원해야 함 (Q&A 10/6에서 허용된 방식)
- 실제 관측소·시각 매핑은 제공하지 않으며, 역추적 금지

## 5. Q&A 결정사항 요약

### 9/21 문의 → 9/23 답변 (참가자 정환웅)
- test에서 같은 관측소의 t+1~t+6 행 `wl_t`로 정답 복원 가능(test 약 61.8% 행) → **금지 확인**. 운영측이 제출 코드를 재현·검증한 결과를 공식 점수로 사용
- 문제정의서의 초기 수치(466개 관측소, 210만 행, Validation 세트 등)는 폐기. 현재 홈페이지·배포 데이터가 최종 기준
- 기준선은 배포 Train 기준으로 재산출 (0.410 / 0.275 / 0.244)
- 보조지표는 순위 미반영
- 익명화로 외부 추가 데이터 결합 불가. 매핑 제공 없음
- 최종 예측 CSV 외에 학습·추론 코드, 실행환경·라이브러리 정보, 방법론 문서 제출 필요

### 9/30 문의 → 9/30 답변 (데이터랩스 송태은)
- 결과 제출 시기는 추후 공지. **마감 전 재제출 가능, 마지막 제출본이 최종**
- 제출물 구성·양식은 공지사항 「2026 DATA·AI 분석 경진대회 개발결과물 제출 안내」 기준 (팀에서 아직 내용 미확인)

### 10/4 문의 → 10/6 답변 (나래팀 이경학, 출제자 답변)
- 허용: (가) 같은 관측소 이전 시각 행 정보(예: 사상 시작 이후 경과시간) / (나) 같은 사상 다른 관측소의 시점 t 입력값 / (다) 같은 사상 다른 관측소의 t 이전 입력값
- 금지: t 이후 행을 이용해 사상 종료시점·전체 사상 길이 등 미래 의존 정보 생성
- 관측소 간 관계를 학습할 때는 train으로 구성
- train의 미래 시점 값(예: 미래 강우)을 **보조모델 학습 라벨로 쓰는 것은 허용**. 단 test에서는 t 이하 입력으로 만든 보조모델 예측값만 사용
